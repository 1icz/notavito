# NotAvito

Учебный проект аналога платформы объявлений, разработанный на Django в рамках практической работы. Проект включает в себя управление пользователями, публикацию объявлений и использование шаблонов для отображения интерфейса.

## Структура проекта

Репозиторий имеет следующую структуру каталогов и файлов:
* **ads/** — приложение для управления объявлениями (модели, представления, формы).
* **users/** — приложение для управления пользователями (регистрация, авторизация, профили).
* **config/** — конфигурационные файлы проекта Django (settings, urls).
* **templates/** — общие HTML-шаблоны интерфейса.
* **manage.py** — скрипт управления Django.
* **requirements.txt** — список зависимостей проекта.
* **Dockerfile** и **docker-compose.yml** — конфигурация для контейнеризации и быстрого развертывания проекта через Docker.
* **.env.example** — пример файла с переменными окружения.

## Стек технологий

* Python
* Django
* Docker / Docker Compose
* PostgreSQL / SQLite (в зависимости от конфигурации в config)

## Установка и запуск

### Запуск через Docker (рекомендуется)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/1icz/notavito.git
   cd notavito
   ```

2. Скопируйте файл с переменными окружения и настройте его при необходимости:
   ```bash
   cp .env.example .env
   ```

3. Запустите контейнеры:
   ```bash
   docker-compose up --build
   ```

### Локальный запуск (без Docker)

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com/1icz/notavito.git
   cd notavito
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/macOS
   # или
   venv\Scripts\activate     # Для Windows
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Скопируйте файл конфигурации окружения:
   ```bash
   cp .env.example .env
   ```

5. Выполните миграции базы данных:
   ```bash
   python manage.py migrate
   ```

6. Запустите сервер разработки:
   ```bash
   python manage.py runserver
   ```

Проект будет доступен по адресу: http://127.0.0.1:8000/
